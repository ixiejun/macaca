# Tools

Use `playwright_search` for web research.

Recommended calls:

```json
{"action":"search","args":["DeepSeek V4 analysis latest sources","--max-results","8"]}
```

```json
{"action":"fetch_url","args":["https://example.com/source"]}
```

Use `file_write` for `shared/research/source-pack.md` and related notes.

Use `file_read` to inspect existing research before updating it.
