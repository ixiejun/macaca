App-level button + dialog

Keep the normal right panel unchanged. Add a generic application operation button, then show schedule management in a modal dialog detached from sessions and agents.

Implementation shape

Add an app-level button near the page header, for example APP OPERATIONS or AUTONOMY. Clicking it opens a modal dialog that contains the existing schedule manager. This keeps Autonomy visible as application capability, but not permanently competing with agents/tasks.
